# mapplat-page
## Features

+ 账号登陆注册（jwt）
+ 文件的上传下载（续传、秒传）
+ 文件导入数据库 （用ogr 到入 csv，geojson，shp）
+ 动态添加数据库链接信息（todo）
+ 查看、管理数据库已有数据（增删）（修改）
+ 用户权限管理（todo admin, manager)
+ config ，配置地图，发布服务gallery，获取可视化ak
+ 根据ak获取config渲染数据（z,x,y）
+ 形式包括png，geojson,矢量瓦片
